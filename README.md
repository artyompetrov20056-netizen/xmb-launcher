# XMB — рабочий стол Android в стиле PS3

Лаунчер, который выглядит как меню PlayStation 3: переливающийся фон с волнами,
белые иконки категорий, список приложений под выбранной категорией, часы в углу.

**Особенность:** раскладка зависит от того, как держишь телефон.

| Положение | Категории | Содержимое |
|---|---|---|
| Горизонтально | строка сверху (как на PS3) | столбик вниз |
| Вертикально | столбик слева | строка вправо |

При повороте иконки плавно перетекают из одной раскладки в другую.

## Категории

- **Настройки** — Wi‑Fi, Bluetooth, экран, звук, цвет темы, выбор рабочего стола, все настройки
- **Фото / Музыка / Видео / Игры / Сеть** — приложения раскладываются сами по тому, как их отметил разработчик в Google Play (браузеры и соцсети попадают в «Сеть»)
- **Приложения** — все установленные приложения по алфавиту

Меню само обновляется при установке и удалении приложений.

## Управление

- Свайп вдоль строки категорий — сменить категорию
- Свайп поперёк — листать приложения
- Нажатие на иконку — выбрать её, повторное нажатие (или нажатие на название) — открыть
- Долгое нажатие на приложение — системная страница приложения (там можно удалить)
- «Назад» или «Домой» — вернуться к первому пункту
- Геймпад или клавиатура: крестовина и кнопка A / Enter

## Как получить APK

### Вариант 1. Android Studio (проще всего на компьютере)
1. Установи [Android Studio](https://developer.android.com/studio).
2. File → Open → выбери папку `xmb-launcher`. Подожди, пока докачается всё нужное.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. GitHub, без установки чего-либо
1. Создай пустой репозиторий на GitHub и загрузи туда содержимое папки `xmb-launcher`
   (вместе со скрытой папкой `.github`).
2. Открой вкладку **Actions** — сборка запустится сама (около 3–5 минут).
3. Открой завершённую сборку, внизу в **Artifacts** скачай `xmb-launcher-apk`, внутри будет APK.

## Установка и выбор как основного

1. Перекинь APK на телефон и открой его. Если Android спросит — разреши установку из этого источника.
2. Нажми кнопку «Домой» → выбери **XMB** → «Всегда».
   Если окно выбора не появилось: Настройки → Приложения → Приложения по умолчанию → Главный экран → XMB.
3. Чтобы раскладка менялась при повороте, должен быть включён **автоповорот** экрана.

## Как убрать

- Временно: XMB → Настройки → «Рабочий стол по умолчанию» → выбрать стандартный.
- Совсем: удалить приложение XMB, телефон сам вернётся к стандартному рабочему столу.

## Где что менять

- `XmbView.kt` — внешний вид, анимации, размеры, жесты (`updateMetrics()` — все отступы и расстояния)
- `Glyphs.kt` — иконки категорий
- `Model.kt` — цветовые темы
- `MainActivity.kt` — состав категорий и пунктов настроек
- `AppRepository.kt` — по каким признакам приложения попадают в категории
